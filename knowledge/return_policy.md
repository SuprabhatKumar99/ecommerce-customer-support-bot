# Returns & Refunds Policy

### 30-Day Return Window
Items can be returned within 30 days of the recorded `DELIVERED` date. Items must be in original condition with packaging and tags intact.

### Non-Returnable Items
- Opened personal hygiene and consumable items.
- Gift cards and downloadable software licenses.
- Final clearance items explicitly marked as non-refundable.

### Refund Processing
Once a return is received at our distribution center, refunds are processed within 3 to 5 business days to the original payment method. If a refund fails or is disputed, an agent escalation ticket is created immediately.
